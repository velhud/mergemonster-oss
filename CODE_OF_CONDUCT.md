# Code of Conduct

MergeMonster contributors and maintainers are expected to keep project spaces
respectful, constructive, and accessible. Harassment, discrimination,
intimidation, personal attacks, and deliberate disruption are not acceptable.

Raise concerns privately with the repository maintainers using the contact
method listed in the repository profile. Do not include private credentials,
personal data, or security-sensitive details in a public issue. Maintainers may
edit or remove harmful content and may restrict participation when needed to
protect contributors.

This policy applies to issues, pull requests, discussions, reviews, and other
project-managed spaces.
